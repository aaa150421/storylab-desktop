기기 변경이나 앱 데이터 손실에 대비해 주기적으로 백업 파일을 저장해 주세요. 백업은 현재 선택한 작업 공간의 작품과 참고 자료를 저장합니다.

백업 파일은 JSON 형식으로 저장됩니다.

ⓘ저장 방식 안내내 작업이 어디에 저장되는지 확인⌄
이 PC의 앱 저장 공간에 자동 저장

작업 공간마다 작품, 원고, 인물과 메모가 별도로 저장됩니다. 앱을 삭제하거나 앱 데이터를 초기화하면 저장 내용이 사라질 수 있습니다.

중요한 작업은 백업 및 복원에서 JSON 백업 파일을 내려받아 별도로 보관해 주세요. 백업 파일은 안전한 폴더에 보관하고, 복원 전에는 현재 작업도 백업하는 것을 권장합니다.
